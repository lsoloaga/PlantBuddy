# PlantBuddy
Application that takes a natural language description of desired plant characteristics and returns a list of plants including a language description and image of each one.
API KEYS will be submitted privately

In order to run: 
Open a venv on gpu00 and run: 
pip install flask
pip install openai
Then run: python3 app.py
Once it's running find the front end with the chatbox at : http://127.0.0.1:5000
